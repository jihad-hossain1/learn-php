- For existing project when clone from github `run this command`

```bash
composer install
```

- Install Nodejs dependency

```bash
npm install && npm run build
```

- For run exiting project run this

```bash
composer run dev
```

- For Database migration command

```bash
php artisan migrate:fresh
```

- For `APP KEY` generate run this command

```bash
php artisan key:generate
```

- Install api from laravel package

```bash
php artisan install:api
```
